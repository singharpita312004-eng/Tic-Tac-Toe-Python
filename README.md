# Tic-Tac-Toe Game 🎮

Simple Tic Tac Toe game made using Python Tkinter.

## How to Run
1. Make sure Python is installed
2. Run: `python Tick_tack_Toe_Game_Basic.py`

## Features
- 2 Player game
- Clean UI with Tkinter
- Shows winner/tie
